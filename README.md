#  Student API - DevOps Project 

##  Description 
This project is a REST API for managing students. 
It demonstrates DevOps practices including testing, containerization, and CI/CD automation.

---

##  Features 
- Retrieve list of students
- Add new student
- Get application information using environment variables

---

##  Technologies 
- Python (Flask)
- Pytest (unit testing)
- Docker (containerization)
- GitHub Actions (CI/CD)

---

##  Run locally 

```bash
python app.py
